# Feature Specification: 005 - 测验生成与闪卡（主动学习）

**Feature Branch**: `005-quiz-flashcards`

**Created**: 2026-07-29

**Status**: Draft

**Input**: 用户讨论：参考市面 AI 学习产品（Knowt/Notta/NotebookLM/CogniGuide），现有"转写+总结+问答"已是标配，差异化在"主动学习"环节——测验、闪卡、间隔重复。本版先做测验生成 + 闪卡。

---

## 背景与定位

市面同类产品的共性：**转写与总结是标配，真正的差异化在"主动学习"**——学完如何记住、如何检验。当前项目已具备转写、OCR/视觉、三级总结、RAG 问答（单课/学习集/全局）、时间戳跳转、诊断页，但缺"学完之后怎么办"。

本版新增**测验生成**与**闪卡**两个主动学习能力，复用已有的课程全文与学习集范围。

**已确认的决策（用户拍板）：**
- 出题方式：**一键批量生成并存库**（非对话式即时出题）
- 闪卡复习：**简单三档标记**（认识/模糊/不认识），SM-2 间隔重复留后续
- 范围：**支持单课程 + 学习集**（与 004 打通）
- 重复生成：**追加**（题库越刷越厚），提供"清空重生成"
- 题型：第一版只做**选择题 + 判断题**（可自动判分）；**简答题留到后续迭代**（需 LLM 判分）

---

## 用户场景与测试

### User Story 1 - 测验生成（Priority: P1）

学生对一门课或一个学习集一键生成自测题（选择/判断），作答后自动判分并显示解析，来源可跳回视频时间点。

**Why this priority**: 解决"看完就忘、不知道自己掌握没"的最高频痛点，是本版核心。

**Independent Test**: 对课程 1 点"生成测验"，得到 10 道选择/判断题；作答后判分正确，解析可见，点来源跳回视频对应时间。

**Acceptance Scenarios**:

1. **Given** 课程已处理完成，**When** 用户点"生成测验"，**Then** 后端基于课程全文一次生成 10-20 道选择/判断题并存库，前端展示题目列表。
2. **Given** 测验已生成，**When** 用户作答并提交，**Then** 选择/判断自动判分，显示对错、正确答案与解析。
3. **Given** 题目有来源，**When** 用户点来源，**Then** 跳转到对应课程的对应视频时间点。
4. **Given** 已生成过测验，**When** 再次点"生成测验"，**Then** 新题追加到题库（不覆盖旧题）。
5. **Given** 题库已有题，**When** 用户点"清空重生成"，**Then** 删除该范围旧题后重新生成。
6. **Given** 针对学习集生成，**When** 出题，**Then** 题目覆盖集合内多门课，来源标注具体来自哪门课。

---

### User Story 2 - 闪卡（Priority: P1）

学生对一门课或一个学习集一键生成记忆闪卡（正面概念/背面解释），可逐张翻看并标记"认识/模糊/不认识"。

**Why this priority**: 与测验共享"从课程内容出题"的底层逻辑，是另一种主动回忆方式，成本几乎相同。

**Independent Test**: 对课程 1 点"生成闪卡"，得到一叠卡片；能逐张翻背面，并标记三档熟悉度，统计各档数量。

**Acceptance Scenarios**:

1. **Given** 课程已处理完成，**When** 用户点"生成闪卡"，**Then** 后端生成一叠正/反面卡片并存库。
2. **Given** 闪卡已生成，**When** 用户翻看，**Then** 默认显示正面，点击翻转为背面解释，可切换上一张/下一张。
3. **Given** 用户在看某张卡，**When** 标记"认识/模糊/不认识"，**Then** 记录该卡熟悉度并持久化。
4. **Given** 卡片有熟悉度标记，**When** 用户查看统计，**Then** 显示认识/模糊/不认识各多少张，可筛选只看"模糊+不认识"。
5. **Given** 卡片有来源，**When** 用户点来源，**Then** 跳转到对应课程对应时间点。

---

## 功能需求

- **FR-1**: 系统 MUST 支持对单课程或学习集一键批量生成测验题（选择/判断），并存库。
- **FR-2**: 重复生成 MUST 追加新题而非覆盖；MUST 提供"清空重生成"。
- **FR-3**: 选择/判断题 MUST 自动判分，显示对错、正确答案与解析。
- **FR-4**: 系统 MUST 支持对单课程或学习集一键批量生成闪卡（正/反面）。
- **FR-5**: 闪卡 MUST 支持翻转查看与三档熟悉度标记（认识/模糊/不认识），并持久化与统计。
- **FR-6**: 题目与卡片的来源 MUST 带课程名与真实时间戳，可跳回视频对应时间点。
- **FR-7**: 针对学习集生成时，题目/卡片 MUST 标注具体来自集合内哪门课。
- **FR-8**: 数据模型新增 Question、Flashcard 表，记录范围（course_id 或 study_set_id）与来源。

---

## 成功标准

- **SC-1**: 对一门课 1 次点击即可得到 ≥10 道可作答、可判分的题目。
- **SC-2**: 选择/判断判分 100% 准确（基于预设答案）。
- **SC-3**: 闪卡熟悉度标记持久化，刷新后统计不丢失。
- **SC-4**: 题目/卡片来源 100% 可跳回视频对应时间点。

---

## 边界 / 非目标（本迭代不做）

- **简答题**：需 LLM 二次判分，留到后续迭代。
- **SM-2 间隔重复复习队列**：闪卡先做三档标记，遗忘曲线调度留后续。
- **错题本**：测验错题自动归集与针对重练，留后续。
- **导出（Markdown/PDF/Anki）**：留后续。
- **音频播客讲解**（NotebookLM 式）：不在本版范围。

## 版本范围（经讨论确定，多迭代）

005 是一个大版本，按迭代分批交付：

**第一迭代（核心主动学习）**
- 测验生成（选择/判断，一键批量存库，自动判分，追加式，来源可跳转）

**第二迭代（数据闭环 + 学伴感）**

- B. 错题本（测验错题归集 + 针对重练）
- D. 笔记 + 时间戳书签（看视频随手记，可跳回）
- F. 导出（Markdown / Anki 牌组）
- **G. 咕咕嘎嘎小企鹅学伴（优先级提升，见下）**
- H. 学习 streak 连续打卡（火焰徽章、里程碑）

**第三迭代（可选 / 视进度）**
- C. 知识点思维导图 / 大纲可视化
- K. 学习周报

**明确留到 006**
- J. 学伴主动关心（"要不要测两道巩固"）
- I. 闯关 / 等级体系
- **实时语音连续对话**（电话式边说边答）
- 简答题 + LLM 判分
- 闪卡 SM-2 间隔重复复习队列

**明确不做**
- E. 音频播客讲解（NotebookLM 式，中文 TTS 双人对话不成熟）

## User Story G - 咕咕嘎嘎小企鹅学伴（Priority: P1，第二迭代）

把 AI 从"问答机器"升级为**有外形、有动作、有语音的可视化学伴**——这是"AI 学伴"定位的灵魂。

**形态**：常驻右下角的小企鹅（咕咕嘎嘎形象，使用网上现成素材，本地个人学习用途）。

**能力拆解（本版范围）：**
- **外形 + 动作**：多状态序列帧/Live2D——待机眨眼、答对开心跳、答错歪头、加载转圈、打卡举牌。前端按状态切换。
- **语音播报（TTS）**：测验判分后语音反馈（"答对啦！这道考的是关联分析～"）、朗读讲义。用 edge-tts（微软免费中文语音）或 Web Speech API。
- **语音输入（ASR）**：按住麦克风说话提问，Web Speech API 转文字。
- **人设**：咕咕嘎嘎语气、鼓励式教学，贯穿问答/测验/闪卡。

**明确留到 006**：实时连续语音对话（边说边答、可打断）。

**素材说明**：咕咕嘎嘎用网上现成素材（本地个人学习用）。实现时搜集/整理一套动作序列（待机/开心/歪头/转圈/举牌），做成 web 可用的序列帧或 GIF 雪碧图。

**Independent Test**: 打开课程页，右下角出现小企鹅；答对题它开心跳并语音鼓励；按住麦克风说话能转成提问文字。

**Acceptance Scenarios**:

1. **Given** 用户在课程/学习页，**When** 页面加载，**Then** 右下角显示小企鹅待机动画（眨眼/呼吸）。
2. **Given** 测验判分完成，**When** 答对，**Then** 企鹅播放开心动作并语音鼓励（TTS）。
3. **Given** 用户按住麦克风说话，**When** 松开，**Then** 语音转为文字填入提问框。
4. **Given** 连续学习达成打卡，**When** 触发，**Then** 企鹅举牌/庆祝动作。

## 假设

- 出题复用 `_load_course_full_text` 获取课程全文；学习集则拼接集合内多门课全文（控制上下文长度，超限截断或抽要）。
- LLM 以结构化（JSON）输出题目/卡片，后端解析存库；解析失败有重试或降级。
- 一门课/集合可多次生成，题库随生成次数增长（追加式）。
- 小企鹅语音用 edge-tts / Web Speech API，无需额外语音服务部署；语音输入用 Web Speech API（浏览器原生）。
- 咕咕嘎嘎素材为本地个人学习用途；若未来对外发布需替换为原创形象。
